📥 Скачать видос целиком

Просто скачать YouTube видео файлом. Без анализа, без нарезки. Можно с диапазоном времени, можно только аудио, можно с субтитрами. Файлы попадают в youtube-analyzer/v1/downloads/<video_id>/.

📤 Загрузить свой видос с субтитрами

Заливаешь свой mp4/mov/mkv → Whisper транскрибирует речь → ffmpeg вшивает субтитры в кадр. Тот же style picker что у скачивания. Файл попадает в youtube-analyzer/v1/uploads/<run_id>/.

📸 Скачать Instagram Reel

Только публичные reels/posts по ссылке. Без cookies, без логина — что 403'ит, то не наше. Файл попадает в youtube-analyzer/v1/insta/<reel_id>/. Опционально Whisper транскрипция + burn (тот же модуль что и в скачать/загрузить).

Скачанные

🎵 Скачать TikTok видео

Только публичные видео по ссылке. Принимает каноничные URL (tiktok.com/@user/video/...) и короткие (vm.tiktok.com/..., vt.tiktok.com/...). Файл попадает в youtube-analyzer/v1/tiktok/<video_id>/.
